# Node.js 学习索引

## 1. 这组文档是干什么的

这组文档用来帮你建立 Node.js 的基础认知。

目标不是一次讲到很深，而是先把最容易混在一起的几个概念拆开：

- Node.js 是什么
- `npm` 是什么
- `package.json` 是什么
- 模块系统是什么
- 异步编程在 Node.js 里为什么这么重要

---

## 2. 建议学习顺序

建议按下面顺序阅读：

1. `basics/knowledge.md`
2. `npm/knowledge.md`
3. `package-json/knowledge.md`
4. `modules/knowledge.md`
5. `async/knowledge.md`

这个顺序的原因是：

- 先知道 Node.js 是什么
- 再知道依赖和命令怎么管理
- 再知道项目配置文件怎么读
- 再知道代码怎么组织
- 最后再理解为什么 Node.js 里异步这么重要

---

## 3. 适合谁看

这组文档适合下面这些情况：

- 刚开始学 Node.js
- 能运行 `node` 命令，但不知道背后在干什么
- 经常看到 `npm install`、`package.json`、`import`，但理解不扎实
- 想继续往 TypeScript、MCP、后端开发方向学

---

## 4. 学完后的目标

学完后，你应该至少能做到：

1. 说清楚 Node.js 是运行时，不是语言
2. 说清楚 `npm` 和 `package.json` 的作用
3. 看懂一个简单 Node.js 项目的基础结构
4. 理解为什么很多 Node.js 代码里会出现 `async/await`
