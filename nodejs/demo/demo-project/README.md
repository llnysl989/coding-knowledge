# Node.js 最小运行示例

## 1. 这个示例做了什么

这个示例只有一件事：

- 定义一个 `greet()` 函数
- 输出 `Hello, Node.js`

它的目标不是演示复杂功能，而是帮你先把最基本的 Node.js 运行流程跑通。

---

## 2. 文件说明

- `index.js`：示例代码
- `package.json`：项目配置文件

---

## 3. 怎么运行

进入目录：

```bash
cd /Users/zyb/project/coding-knowledge/nodejs/demo/demo-project
```

直接运行：

```bash
node index.js
```

或者用脚本运行：

```bash
npm run start
```

---

## 4. 预期输出

```text
Hello, Node.js
```
